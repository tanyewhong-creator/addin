## What is A/addin

A/addin (pronounced *Aladdin*) is a local-first autonomous AI operator. The fork curates
upstream's feature set, rebrands the user-facing surfaces, and rebuilds the web dashboard
on a custom monochrome component library. Internal package names, configuration keys, and
file system paths from upstream are intentionally preserved to keep merges sustainable;
see the Surface Branding Principle in `docs/spec.md` for details.
